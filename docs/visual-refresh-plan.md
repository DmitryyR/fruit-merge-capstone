# Оновлення оформлення — погоджений обсяг

04.10.2026. Користувач погодив згенерований макет повідомленням «так». Пряма корекція користувача: залишити поточну посудину. Макет є напрямом оформлення, не точним кресленням нової геометрії.

## Обмеження

Світ 480×720, стінки x=24/456, дно y=696, радіуси, input, очки, danger та pause/restart не змінюються. Немає бджілки, бонусів, множника або неактивних кнопок. Каталог відповідає 30 фруктам на наданих аркушах. SalesHub не змінювати.

## Задача 1: графічні ресурси

Підготувати садовий фон із дерев'яним столом і 30 окремих прозорих PNG у стилі референсів через imagegen. Зберегти походження, промпти й файли у проєкті. Оглянути ресурси, перевірити прозорість і доступність усіх 30. При потребі прозорі поля враховувати у відображенні, не змінюючи колайдери.

## Задача 2: інтеграція

Оновити каталог, завантаження PNG, CSS панелей та декор поля. Зберегти семантичні кнопки, контраст, focus, усі стани гри й адаптивність. Доказ: скриншоти desktop 1440×900 та mobile 390×844, огляд усіх фруктів, наявні перевірки завантаження, колайдерів, input, lifecycle та помилок.

## Задача 3: перевірка і PR

Виконати повний `npm run check`, зберегти фактичний лог. Передати diff окремому reviewer. Виправити підтверджені значущі проблеми з regression-перевіркою. Оновити current-state, evidence, asset register, README і посилання на ревізію у чинному draft PR. Оновити локальний preview. Відео й здача на платформі залишаються окремими незавершеними кроками.

# Відтворення фінального відео

Фінал: 113.633 с, 1920×1080, H.264/AAC, 30 fps. Голос Microsoft `uk-UA-OstapNeural`, Male, rate -3%. Синтезований оповідач, не клон голосу учасника. Відео, MP3, SRT і raw лежать у `artifacts/capstone/` та виключені зі звичайного git.

Залежності: Node 24, Playwright 1.63.0 із Chromium (package-lock); Python 3; локально встановлені `edge-tts==7.2.8`, `imageio-ffmpeg==0.6.0`, `truststore==0.10.4`. Imageio постачає FFmpeg 7.1 з libx264/libass/loudnorm. Для HTTPS використано системне довірене сховище через truststore, TLS-перевірку не вимикали.

Із кореня репозиторію, використовуючи робочі Python/Node поточного середовища:

```text
python -m pip install --target .local/video-python edge-tts==7.2.8 imageio-ffmpeg==0.6.0 truststore==0.10.4
npm ci
npx playwright install chromium
npm run build:e2e
npx vite preview --outDir dist-e2e --host 127.0.0.1 --port 4180 --strictPort
```

Окремо, не закриваючи preview:

```text
python -X utf8 scripts/capstone/narrate.py
node scripts/capstone/record-demo.mjs
python -X utf8 scripts/capstone/build-video.py
```

`narrate.py` відправляє лише затверджений фактами текст `narration-segments.json` у Microsoft Edge TTS, як прямо доручено в розділі 7 користувацького TXT. Залежить від доступності зовнішнього сервісу. WordBoundary отримано з фактичного синтезу. Перший довгий варіант мав158.7с; текст скорочено, фінальний голос112.36с. Кожна сцена доповнена короткою паузою до межі кадру.

`record-demo.mjs` відкриває власний ізольований Chromium, готує явно позначену сцену через E2E API, потім використовує реальні mouse events. Перший merge1+1→2 дає10; додатковий merge може підвищити рекорд до30, тому restart порівнюється з фактичним значенням перед ним. API не викликає merge або award напряму. Пауза перевіряється незмінним snapshot. Кадри доказів формуються з реальних файлів/git history; зміни — лише переноси рядків та вибір явно підписаних фрагментів. `CAPSTONE_FRAMES_ONLY=1` перегенеровує тільки кадри доказів. `CAPSTONE_DEMO_URL` дозволяє іншу адресу спеціальної E2E-збірки.

`build-video.py` монтує запис у нормальній швидкості, 4 статичні кадри доказів, нормалізує аудіо двома проходами та створює до двох рядків субтитрів за часовими межами слів. Для AAC залишено запас піка: master TP=-2dB, фінальний вимір -1.92dBTP; -16.21LUFS. Перший варіант після AAC мав-1.42dBTP, тому перезібрано з більшим запасом. Музики немає. Субтитри займають окрему нижню смугу, не закривають рахунок або ігрове поле.

Raw зберігає webm, голос по сценах, JSON timestamps, HTML/PNG кадрів, diff, монтажні проміжні файли, команди через код скрипта й журнали FFmpeg. Повторний синтез/запис може змінити байти й випадкову чергу фруктів; перевірки та факти мають зберігатися. Скрипт завершується помилкою при невдалому FFmpeg або ігровому assertion.

Публікація: три фінальні файли — release `capstone-video-v1`. CI після повного check завантажує лише MP4 до Pages artifact і перевіряє зафіксований SHA-256. Жодне MP4/MP3 не зберігається у звичайному git. Після повторного монтажу потрібні нова release-версія, новий digest та перевірка публічного програвача; старий файл не підміняти непомітно.

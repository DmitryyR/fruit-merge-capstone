# Фактичні діаметри фруктів

04.10.2026. Одиниці — логічні px ігрового світу 480×720. Внутрішня ширина 432 px. Ріст між рівнями: 8.7633%.

Тіло — більша вісь вручну відкаліброваного основного тіла без листя/хвостика, помножена на фактичний render scale. Це калібрування ілюстрації, а не автоматична сегментація. Фізика Ø — 2×circleRadius; AABB — виміряна ширина полігонального наближення Matter при куті 0. Незначна різниця AABB та Ø очікувана. Силуети груші/авокадо тощо некруглі, зазор уздовж коротшої осі зберігається.

Baseline: ac040fa; до зміни радіуси 12+1.5×(rank−1). Після: 15.12×(172.8/15.12)^((rank−1)/29).

Відтворення after-вимірювань: `npm run build:e2e`, запустити `npx vite preview --outDir dist-e2e --port 4180`, в іншому терміналі `node scripts/capture-size-evidence.mjs`. Скрипт створює власний ізольований браузер без доступу до користувацького профілю. `FRUIT_EVIDENCE_URL` дозволяє інший тестовий порт. Before JSON знято з попередньої збірки до оновлення; нова збірка його не переписує.

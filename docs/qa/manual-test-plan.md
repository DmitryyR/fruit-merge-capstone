# Візуальна та ручна перевірка

Дата: 04.10.2026. Середовище: Windows, Chromium через Playwright. Сцену для скриншотів явно підготовлено через E2E API, без штучного нарахування очок.

| Перевірка | Результат |
|---|---|
| [Desktop 1440×900](../evidence/screenshots/desktop.png) | Оглянуто: заголовок не перекриває поле, HUD і всі 30 іконок читабельні, controls видимі |
| [Mobile 390×844](../evidence/screenshots/mobile.png) | Оглянуто: немає горизонтального overflow, поле й обидві кнопки поміщаються |
| Миша/дотик | Реальні браузерні input actions в E2E; фізичний дотик на пристрої не виконувався |
| Пауза/restart/рекорд | Автоматизовані browser сценарії, не самостійна тривала ручна партія |
| Високі рівні | Синтетичні сцени та автоматичні тести геометрії; не досягнуті вручну |

Перед записом учаснику: зіграти 1–2 хвилини, перевірити кнопку паузи й нову гру, за можливості відкрити на власному телефоні. Записати пристрій і результат, не замінювати ці рядки вигаданим pass.

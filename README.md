# Фруктовий сад · Fruit Merge

Браузерна гра: скидай фрукти в посудину, поєднуй однакові й збирай очки. TypeScript, Vite, Phaser/Matter; без сервера й акаунтів.

## Запуск

Потрібні Node.js 22.12+ (перевіряється на Node 24), npm та сучасний браузер.

```sh
npm ci
npm run dev
```

Відкрий http://127.0.0.1:5173. Для production: `npm run build`, потім `npx vite preview`.

Мишею обери місце й натисни/відпусти; на телефоні торкнися поля. Однакові фрукти рівня n дають рівень n+1 та 10×n очок. Пауза зупиняє фізику й таймери; «Нова гра» очищує партію, зберігаючи рекорд у цьому браузері. Фрукт, що затримався понад небезпечною лінією, завершує гру. При переході в іншу вкладку гра автоматично стає на паузу.

## Перевірка

```sh
npm ci
npx playwright install chromium
npm run check
```

У Linux CI для браузера: `npx playwright install --with-deps chromium`.

`check` зупиняється при першій помилці й виконує typecheck, lint, unit, integration, production build, окремий E2E build та Playwright на 1440×900 і 390×844, включно з production smoke. Повний вивід не замінюється заглушкою. Окремі команди: `npm run test:unit`, `npm run test:integration`, `npm run test:e2e`, `npm run test:smoke`. Для двох останніх спочатку створити обидві збірки: `npm run build` і `npm run build:e2e`.

Тестовий API є лише в E2E build (`dist-e2e`); у звичайному `dist` відсутній. Тести готують сцени, але перевіряють справжнє керування й зіткнення Matter.
